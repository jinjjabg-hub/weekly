# 위클리 발표 순서 바꾸기

BNI 주간회의 PPT의 "위클리 장표 띄우기" 구역을 발표 순서 명단대로 재배열하는 웹도구입니다.
파일은 서버로 올라가지 않고 브라우저 안에서만 처리됩니다.

## 사용법
1. PPT 파일 올리기
2. 발표 순서 명단 붙여넣기 → 버튼 → `YYYYMMDD_주간회의_순서적용.pptx` 다운로드

- 명단에 없는 사람의 장표는 구역 맨 뒤로 가고 숨김 처리됩니다(삭제 안 함).
- 장표에서 못 찾은 이름은 빨간 글씨로 알려줍니다.

## 배포 (GitHub Pages)
Settings → Pages → Branch: `main` / `(root)` → Save
